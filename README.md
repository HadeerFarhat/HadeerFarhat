# 📚 Learn → Build → Share

This is one of the most important parts of my journey.

Whenever I learn something new — whether from a **course, concept, technology, challenge, or project** — I try to turn that learning into something practical.

Then I share the journey on LinkedIn.

Not because everything has to be perfect.

But because **documenting the process makes learning deeper**.

And sometimes, something I share can help someone else take their first step.
